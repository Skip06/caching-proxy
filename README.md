## 🧩 Installation

Clone this repository and install dependencies:

```bash
git clone https://github.com/yourusername/caching-proxy.git
cd caching-proxy
npm install
```
## 🚀 Features

- ⚡ In-memory caching for fast repeated requests  
- 🌐 Acts as a transparent proxy between client and origin  
- 🧹 One-command cache clearing (`--clear-cache`)  
- 🧾 Custom origin and port configuration  
- 🛡️ Graceful shutdown (`Ctrl + C`)
